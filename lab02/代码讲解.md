## 问题 1　获取所有房源节点

**代码位置**：第二阶段 2 第一个代码单元格。

```python
rows = soup.select("div.property")      # select() 返回列表，一项对应一条房源
```

**怎么回答**：
- `select()` 是 BeautifulSoup 按 **CSS 选择器** 找节点的方法，返回**列表**；括号里的 `"div.property"` 意思是「class 属性为 property 的 div 标签」——在这个页面里，**恰好一个 `div.property` 包住一条房源**（标题、楼盘、地址、属性、价格都在它里面）。
- 顺便可提：找**单个**节点用 `select_one()`（返回第一个匹配或 None），找**全部**用 `select()`（返回列表）。
- **遍历每一条房源**：列表推导式一行完成——

```python
records = [parse_row(r) for r in page_rows]
```

  等价于 `for row in rows:` 循环，每轮把一条房源交给 `parse_row()` 解析成 8 个字段。

## 问题 2　提取具体字段（单价）

**代码位置**：`parse_row()` 函数内部。

```python
# --- 单价：取 property-price-average（元/㎡），不是 property-price-total（总价/万）---
price = text_of(row.select_one("p.property-price-average"))
```

配套的取文字函数：

```python
def text_of(node, default=""):
    if node is None:
        return default
    return node.get_text(strip=True)
```

**怎么回答**：
- **定位节点**：`row.select_one("p.property-price-average")`，在当前这条房源容器内部找 class 为 `property-price-average` 的 p 标签。
- **提取文字**：`get_text(strip=True)` 把标签内文字取出并去掉首尾空白；节点不存在时返回空字符串，避免 None 导致后面报错。
- **为什么是每平米单价（对照网页说）**：安居客每条房源的价格区有**两个数**——左边大字是**总价**（class `property-price-total`，如"185万"），右边小字是**单价**（class `property-price-average`，如"15694元/平米"）。题目要单价，所以选择器取的是 `property-price-average`，取出来就是网页上显示的"××××元/平米"。

## 问题 3　换页采集

**代码位置**：`find_next_url()` + `crawl()` 两个函数（第二阶段 3 第二个单元格）。

**三个位置逐个指**：

```python
a = soup_page.select_one("a.next.next-active")   # ① 找"下一页"按钮
...
return urljoin(current_url, a.get("href"))       # ② 补全地址
...
url = find_next_url(page_soup, url)              # ③ 更新请求地址（while 循环下一轮用）
```

- **获取 href**：`a.get("href")` 取的是 a 标签的 **href 属性**。注意 `get_text()` 拿到的是"下一页"这三个字，不是地址，别取错。
- **补全地址**：href 只有 `?page=2` 这种**相对地址**，`urljoin(当前页地址, href)` 把它拼成完整绝对地址。
- **更新请求地址**：把补全结果赋回 `url`，外层 `while url and page < max_pages:` 下一轮就请求新地址。
- **何时停止翻页**：**末页时"下一页"按钮是被禁用的**——分页区 `.pagination` 还在，但 `a.next.next-active` 找不到（或没有 href），`find_next_url` 返回 `None`，`while url` 条件不成立，循环自然结束。**不能靠页码猜**（比如算总页数），因为禁用状态是页面自己告诉我们的，最可靠。
- 加分点：还有三道保险——`MAX_PAGES` 页数上限防死循环、`visited` 集合防地址重复、域名越出教学站立即停止；每页之间 `time.sleep(1)` 至少等 1 秒。

## 问题 4　CSV 存储

**代码位置**：第二阶段 4 第一个代码单元格。

```python
with CSV_PATH.open("w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(FIELDS)                        # 表头
    for rec in unique:
        writer.writerow([rec[k] for k in FIELDS])  # 每条恰好 8 项
```

**逐项回答**：
- **文件路径**：`data/houseinfo.csv`（`CSV_PATH = DATA_DIR / "houseinfo.csv"`，DATA_DIR 是当前目录下的 data 文件夹）。
- **编码**：`utf-8-sig`——带 BOM 的 UTF-8，用 Excel 双击打开中文不乱码；`newline=""` 是 csv 模块的固定写法，防止 Windows 下写出一行行空行。
- **表头**：`writer.writerow(FIELDS)`，写出的就是 `title,house,address,struct,area,floor,maketime,price`。
- **怎么保证 8 个字段顺序正确**：全程序只有**一个顺序源头**——常量 `FIELDS` 列表。表头按它写，数据行 `[rec[k] for k in FIELDS]` 也按它逐个取值，入库读回时还用 `reader.fieldnames != FIELDS` 校验表头，顺序不一致直接报错。三处共用同一份顺序，想错都错不了。
- 加分点：写 CSV 前按 8 个字段组成的元组做了**完全一致去重**，600 条 → 去掉 102 条重复 → 498 条。

## 问题 5　PyMySQL 批量入库

**代码位置**：第三阶段 `insert_records()` 函数（含 `INSERT_SQL`）。

```python
INSERT_SQL = (
    "INSERT INTO houseinfo (title, house, address, struct, area, floor, maketime, price) "
    "VALUES (%s, %s, %s, %s, %s, %s, %s, %s)"     # 8 个占位符对应 8 个字段
)
...
affected = cur.executemany(INSERT_SQL, to_insert)
```

**怎么回答**：
- **连接数据库**：`conn = pymysql.connect(**DB_CONFIG)`，`DB_CONFIG` 字典里就是第 6 题那些参数。
- **executemany() 的作用**：把第二个参数里的**记录列表**（每条是一个 8 元组）逐条填进 SQL 的 `%s` 占位符，**一次网络往返批量执行**，比循环调 `execute()` 快得多。
- **8 个值怎么对应 8 个 %s**：`to_insert` 里的每条记录是**按 FIELDS 顺序**整理的元组（`load_csv_records()` 里 `tuple(row[k] for k in FIELDS)`），元组第 1 个值（title）填第 1 个 `%s`，第 2 个值（house）填第 2 个 `%s`……位置一一对应，8 个正好填满。值由**参数**传入而不是拼字符串，顺带防了 SQL 注入。
- 加分点（事务三件套）：写完 `conn.commit()` 提交，别的终端才能看到数据；出错 `conn.rollback()` 回滚；`finally` 里先 `cur.close()` 再 `conn.close()`。
- 加分点（为什么重跑不重复插）：自增 id 拦不住重复房源，所以插入前先 `SELECT` 库内已有 8 字段做**集合比对**，只插不存在的——独立重跑新增 0 条。

## 问题 6　PyMySQL 数据库连接参数

**代码位置**：第三阶段第一个代码单元格。

```python
DB_CONFIG = {
    "host": "mysql",          # 课程数据库服务名（Notebook 在容器内，不能用 localhost）
    "port": 3306,
    "database": "smartpark_lab",
    "user": "student",
    "password": "123456",
    "charset": "utf8mb4",
    "autocommit": False,      # 由程序显式提交事务
}
```

**逐参数回答**：
| 参数 | 值 | 含义 |
|---|---|---|
| `host` | `mysql` | 数据库服务器地址。这里是课程容器网络里的**服务名**（Docker 给 MySQL 容器起的名字），Notebook 自己也在容器里，通过服务名访问；在容器外才用 localhost/127.0.0.1 |
| `port` | `3306` | MySQL 默认端口号 |
| `user` / `password` | `student` / `123456` | 课程发的数据库账号密码 |
| `database` | `smartpark_lab` | **要连接的数据库名——本次实验连的就是 smartpark_lab 库**，房源写进其中的 `houseinfo` 表 |
| `charset` | `utf8mb4` | 连接字符集。utf8mb4 是完整版 UTF-8，能存所有中文和特殊字符；用错了终端里中文会变问号（本实验踩过这个坑） |
| `autocommit` | `False` | 关掉自动提交，由程序自己 `commit()`/`rollback()` 控制事务 |

一句话总结版：**连的是课程环境里名为 mysql 服务的 MySQL（3306 端口），用 student 账号进 smartpark_lab 库，字符集 utf8mb4 防中文乱码。**
